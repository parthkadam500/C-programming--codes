C Programming Laboratory Workspace

A collection of foundational C programming programs and laboratory exercises developed as part of my First Year Engineering curriculum.

This repository covers fundamental concepts of C programming, including data types, operators, control statements, loops, arrays, functions, structures, unions, strings, pointers, and file handling.

Technologies Used

- Programming Language: C
- Compiler: GCC
- IDE: Visual Studio Code / Online C Compiler

Learning Objectives

- Understand fundamental C programming concepts.
- Develop logical thinking and problem-solving skills.
- Apply operators, conditional statements and loops.
- Perform operations using arrays and matrices.
- Understand functions and their different types.
- Work with structures and unions.
- Perform string manipulation using library and user-defined operations.
- Understand pointers and pointer-to-pointer concepts.
- Perform file operations such as reading and writing data.

How to Run

1. Clone or download this repository.

2. Open the required ".c" file.

3. Compile the program using GCC:
   
   "gcc filename.c -o output"

4. Run the executable:
   
   "./output"

Purpose

This repository serves as a collection of my C programming laboratory exercises and practice programs, documenting my learning, practical implementation, and progress in C programming.
